# Surpresa para Djenifer

Site romântico feito com HTML, CSS e JavaScript. Para abrir localmente, extraia o ZIP e abra `index.html` no navegador. Mantenha as fotos, os vídeos, `musica.mp3` e `style.css` na mesma pasta do arquivo HTML.

Para publicar como site, crie um repositório no GitHub, envie os arquivos desta pasta e ative o GitHub Pages nas configurações do repositório.
